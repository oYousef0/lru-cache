# Quick LRU Cache

A lightweight, zero-dependency, and high-performance **LRU (Least Recently Used) Cache** implemented in JavaScript, powered by the native `Map` data structure for true $O(1)$ time complexity on all operations.

---

## Features

- **True $O(1)$ Operations:** Fast lookup, insertion, and eviction utilizing JavaScript's native hash map and insertion-order iteration.
- **Zero Dependencies:** Written in pure, vanilla modern JavaScript.
- **Fully Tested:** Comprehensive unit tests built directly with Node.js native test runner.
